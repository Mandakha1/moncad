# Мэдээ, сургалт, зар илгээх (MonCad 2026, MonSolid 2026)

Суулгасан бүх MonCad болон MonSolid програм нэг файлыг уншдаг:
**`news/feed.json`** (энэ repo-ийн `main` салбар,
<https://github.com/Mandakha1/moncad/blob/main/news/feed.json>).

Програм нээгдэх бүрт (нээлттэй үед 6 цаг тутам) энэ файлыг татаад шинэ зүйл байвал:

- баруун доод буланд **карт** гаргана (Нээх / Хаах / Дахиж бүү харуул);
- `"toast": true` бол **Windows мэдэгдэл** бас илгээнэ (суулгагчаар суусан програмд);
- **Тусламж → Мэдээ, сургалт…** цэсэнд бүгдийг жагсаана.

Нийтлэхээс өмнө өөрийн компьютер дээр шалгах: `MON_NEWS_FILE=C:\зам\feed.json` орчны хувьсагчтайгаар програмыг нээвэл тэр файлыг уншина.

Нэг мэдээ нэг хүнд нэг л удаа гарна (хаасныг дахин харуулахгүй). Програм зөвхөн энэ файлыг татдаг,
хэрэглэгчийн тухай юу ч илгээдэггүй. Хэрэглэгч картыг унтрааж болно.

## Шинэ мэдээ нэмэх (утаснаас ч болно)

1. GitHub дээр `news/feed.json` → ✏️ (Edit).
2. `"items"` жагсаалтад шинэ мөр нэмнэ:

```json
{
  "id": "2026-12-shine-surgalt",
  "products": ["moncad", "monsolid"],
  "kind": "course",
  "title": { "mn": "12-р сарын шинэ сургалт", "en": "New course in December" },
  "body": { "mn": "Бүртгэл нээгдлээ, 20% хямдрал 12/10 хүртэл.", "en": "Registration is open, 20% off until 12/10." },
  "link": "https://cad.monhydro.com",
  "link_label": { "mn": "Бүртгүүлэх", "en": "Sign up" },
  "start": "2026-12-01",
  "end": "2026-12-10",
  "toast": true
}
```

3. **Commit changes**. 5–10 минутын дараа програмууд шинэ файлыг харна.

| Талбар | Утга |
|---|---|
| `id` | Давтагдахгүй нэр (жишээ: огноо + сэдэв). Өөрчилбөл хүмүүст дахин гарна. |
| `products` | `moncad`, `monsolid` эсвэл хоёулаа. Хоосон бол бүгдэд. |
| `kind` | `news` (мэдээ), `course` (сургалт), `ad` (зар — картан дээр «Зар» гэж тэмдэглэгдэнэ), `update` (шинэчлэл) |
| `title`, `body` | `mn` ба `en`. Аль нэг нь хоосон бол нөгөөг нь харуулна. |
| `link` | Зөвхөн `https://…` холбоос. |
| `start`, `end` | `ОООО-СС-ӨӨ`, хэзээнээс хэзээ хүртэл харуулах (заавал биш). |
| `toast` | `true` бол Windows мэдэгдэл бас илгээнэ. |

Анхаарах: JSON-д таслал, хашилтыг зөв тавина (алдаатай файлыг програм уншихгүй, юу ч гаргахгүй).
Хадгалахаас өмнө <https://jsonlint.com> дээр шалгаж болно. Зар бол «Зар» гэж тодорхой тэмдэглэгдэнэ;
Монголын Зар сурталчилгааны тухай хуулийн шаардлагыг (худал, төөрөгдүүлэх зар хориотой) дагана уу.
