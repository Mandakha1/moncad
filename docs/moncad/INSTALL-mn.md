# MonCad — суулгах заавар

MonCad бол AutoCAD-тай төстэй, үнэгүй, нээлттэй эхийн 2D CAD програм. Монгол болон англи
интерфейстэй. Гараар зурж болно, эсвэл Claude / ChatGPT-ээр удирдуулж зуруулж болно.

## Windows (10, 11 — 64 бит)

1. `moncad-<хувилбар>-windows-x64-setup.exe` файлыг татна.
2. Давхар товшоод суулгана. Администраторын эрх шаардлагагүй (таны хэрэглэгчийн хавтаст суулгана:
   `%LOCALAPPDATA%\Programs\MonCad`).
   - Windows «SmartScreen» анхааруулга гарвал **More info → Run anyway** дарна (програм одоогоор
     кодын гарын үсэггүй).
3. Start цэс → **MonCad**.

Чимээгүй суулгах: `moncad-<хувилбар>-windows-x64-setup.exe /S` (ширээний товчлолтой бол `/DESKTOP=1`).
Устгах: **Settings → Apps → MonCad → Uninstall**. Таны зургууд болон тохиргоо (`%APPDATA%\MonCad`) устахгүй.

### Шаардлага

- Windows 10/11, 64 бит
- DirectX 12 эсвэл Vulkan дэмждэг видео карт (сүүлийн 8–10 жилийн бараг бүх компьютер)

## macOS

`MonCad.app`-ыг **Applications** хавтас руу чирнэ. Анх нээхэд «unidentified developer» гэвэл
хулганы баруун товч → **Open**.

## Хэл солих

**Edit → Interface Language → Монгол** (эсвэл English). Програм дахин асаах шаардлагагүй.
Windows-ийн хэл Монгол бол MonCad автоматаар Монгол хэлээр нээгдэнэ.

Гарын байрлал Монгол (ФЦУЖЭН) үед ч командыг бичиж болно: «лшиу» гэж бичвэл `LINE`, «ёшжёлу» бол `CIRCLE`.

## Файлын формат

- **DXF** (R12–2018) — найдвартай уншиж, бичнэ. Бусад програмтай солилцоход DXF-ийг зөвлөж байна.
- **DWG** — туршилтын түвшинд. Нээх боломжтой ч зарим объект алдагдаж болно; DWG-ээр хадгалахад
  алдагдах зүйл байвал MonCad урьдчилан анхааруулна. Чухал ажлыг DXF болгон давхар хадгална уу.
- **PDF, SVG, PNG** — хэвлэх/экспорт.
