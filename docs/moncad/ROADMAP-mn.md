# MonCad — Монгол инженерүүдэд зориулсан сайжруулалт

## Хийгдсэн (энэ хувилбарт)

| # | Сайжруулалт | Үр дүн |
|---|---|---|
| 1 | Монгол интерфейс | 2,053 мөр, англи руу буцах мөр 0; Ө ө Ү ү фонтод бүрэн |
| 2 | Монгол гарын байрлалаар команд | «лшиу» = LINE, «елйнуж» = -LAYER — гар солих шаардлагагүй |
| 3 | Метр систем анхнаасаа | Шинэ зураг мм, ISO-25 хэмжээс; AI-ийн headless горим ч мөн адил |
| 4 | AI холболт Windows дээр | `--launch` MonCad-ийг өөрөө нээнэ; суулгагч бэлэн командуудыг `AI-connect.txt`-д бичнэ |
| 5 | AI-д өгөх заавар | MCP сервер AI-д «мм, монгол текст, мэргэжлийн давхарга» гэж зааж өгдөг |
| 6 | Монгол текстийн зай | Зурган дахь кирилл текст Arial / Segoe UI фонтоор зөв зайтай зурагдана (өмнө нь CJK фонтоос авч 2 дахин өргөн байсан) |
| 7 | DWG анхааруулга | DWG-ээр хадгалахад алдагдах объект байвал урьдчилан асууна (CADCraft-аас ирсэн), заавар DXF-ийг зөвлөнө |

| # | Санал | Ач холбогдол | Ажлын хэмжээ |
|---|---|---|---|

| B | **Халаалт, агааржуулалтын блокийн сан**: радиатор, хаалт, насос, зуух, тэлэлтийн сав, Т1/Т2, В1, К1 давхаргын стандарт | Дулааны инженерүүдэд шууд | Дунд |

| D | **Талбай, дулааны алдагдлын тооцоо**: өрөөний полилайнаас талбай → м² хүснэгт; AI-аар дулааны ачаалал тооцоолох загвар | Өндөр | Дунд–их |

| H | **macOS DMG-ийн арын зураг**, Linux багц | Бүрэн брэнд | Бага |
